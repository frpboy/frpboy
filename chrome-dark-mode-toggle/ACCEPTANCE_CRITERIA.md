# Acceptance Criteria - Dark Mode Toggle

- Extension installs and runs in Chrome
- Dark mode toggle works on various websites
- Darkness levels (light/medium/dark) work correctly
- Per-site preferences save and persist
- Keyboard shortcut (Ctrl/Cmd+Shift+D) works
- Settings page allows customization of darkness level
- Can whitelist/blacklist specific sites
- Images and videos are not inverted
- Text remains readable in dark mode
- Works on most major websites without breaking layout
- Documentation includes "Dark Mode Toggle" and frpboy attribution
- No console errors on popular websites
