# Quick Start - Dark Mode Toggle

1. Clone the repo:
   ```bash
   git clone https://github.com/frpboy/chrome-dark-mode-toggle.git
   cd chrome-dark-mode-toggle
   ```

2. Load the extension:
   - Open `chrome://extensions/`
   - Enable developer mode
   - Click "Load unpacked" and select the project folder

3. Toggle dark mode:
   - Click the extension icon or press `Ctrl/Cmd + Shift + D`
   - Adjust darkness level in the popup or settings page
