# Dark Mode Toggle - Project Overview

Dark Mode Toggle is a lightweight Chrome extension that applies a smart, readable dark mode to any website with a single click. Users can customize darkness levels, save per-site preferences, and manage whitelists or blacklists for automatic behavior.

## Key Features

- One-click dark mode toggle
- Smart CSS inversion with layout-safe filters
- Three darkness levels
- Per-site preferences and automatic persistence
- Whitelist and blacklist management
- Keyboard shortcut support
- Settings page for customization
