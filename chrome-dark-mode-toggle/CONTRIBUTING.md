# Contributing to Dark Mode Toggle

Thank you for your interest in contributing to the Dark Mode Toggle Chrome extension! This document provides guidelines and instructions for contributing.

## 🌟 How to Contribute

We welcome contributions of all kinds:

- 🐛 Bug reports
- 💡 Feature suggestions
- 📝 Documentation improvements
- 🔧 Code contributions
- 🎨 Design improvements

## 🚀 Getting Started

### Prerequisites

- Google Chrome browser
- Basic knowledge of HTML, CSS, and JavaScript
- Git installed on your machine
- A GitHub account

### Setup Development Environment

1. **Fork the Repository**
   - Visit the [repository](https://github.com/frpboy/chrome-dark-mode-toggle)
   - Click the "Fork" button in the top-right corner

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/chrome-dark-mode-toggle.git
   cd chrome-dark-mode-toggle
   ```

3. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

## 💻 Development Guidelines

- Use **2 spaces** for indentation
- Use **camelCase** for variable and function names
- Keep functions small and focused
- Test on multiple sites to ensure compatibility

## 🧪 Testing Your Changes

Before submitting a pull request:

1. **Test on Multiple Websites**
   - News sites (CNN, BBC, etc.)
   - Blogs (Medium, personal blogs)
   - Documentation sites (MDN, GitHub docs)
   - E-commerce sites

2. **Test All Features**
   - Dark mode toggle
   - Darkness levels
   - Settings persistence
   - Whitelist/blacklist behavior
   - Keyboard shortcut

3. **Check Console for Errors**
   - Open DevTools (F12)
   - Ensure no console errors or warnings

## 🔄 Pull Request Process

1. Update documentation if you add or change features
2. Ensure settings and preferences still persist
3. Provide screenshots for UI changes
